# Media
In Media, I have established the ability to insert and alter media using p5.js. Upon clicking the clueless cat, he will let out an intimidating meow and become angry, as dictated through the inversion of colours via a filter. The moment a user stops 'poking' the cat, he will revert to his default clueless stance.
