# Media
In Media, I have established the ability to insert and alter media using p5.js. Upon clicking the already-frustrated man, he will become angry and let out a scream, and will become divinely angry, as dictated through the inversion of colours via a filter. The moment a user stops 'poking' the man, he will revert to his default frustrated stance.
